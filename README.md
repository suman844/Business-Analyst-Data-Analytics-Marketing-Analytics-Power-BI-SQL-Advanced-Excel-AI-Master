## 🚀 How to Use These Files

### Power BI Files (.pbix)
1. Download the `.pbix` file
2. Open in Power BI Desktop (2020+ version recommended)
3. Connect to your data sources or use included sample data
4. Explore interactive dashboards and visualizations
5. Study DAX formulas and data model design

### Excel Files (.xlsx)
1. Download and open in Excel 2016 or later
2. Review formulas in formula bar
3. Interact with pivot tables and slicers
4. Examine conditional formatting rules
5. Customize for your own data sources

### SQL Files (.sql)
1. Open in your SQL IDE (MySQL Workbench, SQL Server Management Studio, etc.)
2. Execute database creation scripts
3. Run table creation and data insertion scripts
4. Execute sample queries to understand data structure
5. Modify queries for your analytical needs

### AI Automation Files (.json)
1. Import workflow JSON into n8n application
2. Configure API keys and credentials
3. Connect to your email/Telegram accounts
4. Test workflow with sample triggers
5. Deploy for continuous operation

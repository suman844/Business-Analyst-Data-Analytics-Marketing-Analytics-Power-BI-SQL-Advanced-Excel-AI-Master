# n8n AI Automation Projects

This folder showcases hands-on AI and workflow automation projects developed using n8n and OpenAI, with integrations for business productivity and communication tools.

## 1. AI-Powered Email Assistant | n8n + OpenAI + Gmail

An AI-powered email automation workflow that accepts conversational requests, processes them through an AI Agent with contextual memory, and connects with Gmail for email actions.

**Workflow:** Chat Trigger → AI Agent → OpenAI Chat Model → Memory → Gmail

**Skills demonstrated:** n8n, Generative AI, AI Agents, OpenAI integration, Gmail automation, contextual memory, workflow automation.

**File:** `AI_Email_Assistant_n8n.json`

## 2. AI Personal Assistant | n8n + OpenAI + Telegram + Gmail + Google Calendar

An AI-powered personal productivity assistant that receives requests through Telegram, uses an AI Agent and contextual memory to interpret them, and integrates with Gmail, Google Calendar, and Telegram to support communication and scheduling workflows.

**Workflow:** Telegram Trigger → AI Agent → OpenAI Chat Model + Memory → Gmail / Google Calendar / Telegram

**Skills demonstrated:** Agentic AI, n8n, OpenAI, Telegram integration, Gmail automation, Google Calendar automation, multi-application workflow integration, AI agents, workflow automation.

**File:** `AI_Personal_Assistant_Telegram_n8n.json`

## Business Value

These projects demonstrate how AI agents and workflow automation can reduce repetitive manual tasks, connect multiple business applications, and improve productivity through conversational automation.

## Security Note

Credential references were removed from the portfolio JSON files before publication. Anyone importing these workflows into n8n must configure their own OpenAI, Gmail, Telegram, and/or Google Calendar credentials. No API keys, passwords, OAuth tokens, or account credentials are intentionally included in these portfolio files.
